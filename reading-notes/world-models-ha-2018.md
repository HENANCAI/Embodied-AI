# 文献阅读笔记：《World Models》(Ha & Schmidhuber, 2018)

> 论文原文：[ha_arXiv_2018.pdf](../references/ha_arXiv_2018.pdf)
> 阅读日期：2026-08-10
> 领域：世界模型 / 基于模型的强化学习 / 生成模型
> 交互式在线版：https://worldmodels.github.io

---

## 1. 一句话概括

用**无监督学习**先训练一个环境生成模型（世界模型），再在**世界模型的"梦境"里训练一个极简控制器**，最后把控制器迁移回真实环境——整套流程只用一个 867 参数（CarRacing）/ 1088 参数（VizDoom）的线性控制器就解决了任务。

## 2. 论文要解决的核心问题

| 问题 | 说明 |
|------|------|
| 模型无关 RL 的信用分配瓶颈 | 传统 Deep RL 直接训练大网络很慢，因为信用分配（credit assignment）难 |
| 观测维度高 | 原始像素输入（64×64×3）难以直接学策略 |
| 数据效率低 | 真实环境交互昂贵，希望能少跑真实环境 |

**核心思想**：把智能体拆成"大世界模型 + 小控制器"，把复杂度全部放进可高效监督训练的世界模型，让 RL/进化算法只优化一个极小的控制器。

## 3. 方法：Agent 三组件模型（V-M-C）

智能体由三个紧密协作的组件构成：

```
观测帧 x_t ──→ [V: VAE] ──→ 潜变量 z_t ──┐
                                           ├──→ [C: 控制器] ──→ 动作 a_t ──→ 环境
        [M: MDN-RNN] ←── (a_t, z_t) ──────┘
       隐藏状态 h_t（包含未来预测信息）───────┘
```

### 3.1 V（Vision）— 变分自编码器 VAE
- **作用**：把每一帧 64×64×3 像素压缩成低维潜向量 z（CarRacing 用 32 维，Doom 用 64 维）
- **结构**：ConvVAE，4 层卷积编码 + 4 层反卷积解码，训练用 L2 重建损失 + KL 损失
- **关键**：高斯先验限制了信息容量，也让世界模型对不真实的 z 更鲁棒
- 参数量：CarRacing 4,348,547 / Doom 4,446,915

### 3.2 M（Memory）— MDN-RNN（核心创新）
- **作用**：预测未来。学习 `P(z_{t+1} | a_t, z_t, h_t)`，即给定当前动作、观测和隐状态，预测下一个潜向量
- **结构**：LSTM（256/512 隐单元）+ 混合密度网络输出层（MDN，5 个高斯分量），输出的是**概率分布**而非确定值
- **为什么用混合分布**：环境常有离散随机事件（如怪物决定是否开火），单一高斯表达不了多模态；MDN 能捕捉这类离散模式
- **温度参数 τ**：采样时可调节模型不确定性——τ 低≈确定性 LSTM，τ 高≈更随机的环境。这是全篇的关键旋钮
- 参数量：CarRacing 422,368 / Doom 1,678,785

### 3.3 C（Controller）— 线性控制器
- **作用**：只根据 `[z_t, h_t]` 直接输出动作：`a_t = W_c [z_t; h_t] + b_c`
- **刻意保持极简**：867 / 1088 个参数，用 **CMA-ES 进化策略**优化（不用反向传播）
- **为什么可行**：h_t 由 MDN-RNN 生成，编码了"未来概率分布"的信息——控制器不需要显式规划，只需"本能地"查询 RNN

### 3.4 训练流程（两阶段 + 可选迭代）

```
阶段 1（无监督）: 随机策略采集 10,000 条 rollout → 训练 VAE(V) → 训练 MDN-RNN(M)
阶段 2（策略优化）: 固定 V、M，用 CMA-ES 进化 C，在真实环境（或梦境）中优化累计奖励
可选迭代: rollout → 更新 M → 更新 C → 循环（面向更难任务）
```

## 4. 两个实验

### 4.1 CarRacing-v0（世界模型做特征提取）
- 任务：随机生成赛道，像素输入学习驾驶，平均分 ≥900 视为解决
- **消融对比**（关键实验）：

| 方法 | 平均得分 |
|------|---------|
| 只看 z（无 M） | 632 ± 251 |
| 只看 z + 隐层 | 788 ± 141 |
| **完整世界模型（z + h）** | **906 ± 21 ✅ 解决** |
| A3C (discrete) | 652 ± 10 |
| Gym 排行榜最佳 | 838 ± 11 |

- **结论**：同时给控制器 z（当前观测）和 h（未来预测）才能稳定驾驶；h 让控制器能"攻击弯道"

### 4.2 VizDoom Take Cover（完全在梦里训练 + 迁移）
- 任务：躲避怪物火球，存活 750 时间步视为解决
- **关键改动**：M 额外预测 `d_{t+1}`（是否死亡），从而构成完整的模拟环境
- **流程**：M 学会整个游戏逻辑（物理、敌人行为、碰撞检测）→ 用 Gym 接口包一层 → **控制器完全在潜空间"梦境"里训练**（无需渲染，计算高效）→ 迁移回真实 Doom
- **结果**：梦境训练得分 ~900，迁移到真实环境 **1092 ± 556**（远超 750 的解决线，超过排行榜的 820 ± 58）
- **温度 τ 的妙用**：在梦境里加大 τ 让环境更难，能防止控制器"作弊"并提升迁移鲁棒性

## 5. 重要发现与洞察

### 5.1 "欺骗世界模型"问题（模型利用漏洞）
- 控制器发现对手怪物从不开火的对抗策略——因为世界模型不完美，它利用模型漏洞而非学会真实技能
- **解法思路**：用 MDN 输出概率分布 + 调高温度 τ 增加环境随机性，让漏洞难以被稳定利用
- 这是后续所有"学习型动力学模型"研究都必须面对的问题（π0、Dreamer 等同样处理）

### 5.2 迭代训练程序（面向复杂任务）
- 简单任务一轮就够；难任务需要：rollout → 更新 M → 更新 C 循环
- 提出用 M 的预测误差作为**好奇心/内在动机**奖励（预测差的区域 = 没见过的地方 = 值得探索）

### 5.3 世界模型的三层价值
1. **特征提取**：压缩时空表征给控制器（CarRacing 实验）
2. **梦境训练**：完全在潜空间训练，摆脱真实环境成本（Doom 实验）
3. **迁移**：在更难（更高 τ）的梦境中学到的策略更鲁棒

## 6. 局限与讨论

| 局限 | 说明 |
|------|------|
| VAE 无监督学习与任务无关 | 可能编码任务无关细节（如 Doom 墙砖）而漏掉任务相关特征（如赛车路面） |
| 世界模型容量有限 | LSTM 存不下全部历史，灾难性遗忘；提出可换更大模型或外挂记忆 |
| 无分层规划 | 逐时间步模拟未来，没有类人分层推理；对比 Learning to Think 的通用框架 |

## 7. 与我的研究方向的联系

1. **这是 VLA 之前的世界模型原型**：V-M-C 架构 ≈ 现代 VLA 的"感知编码器 + 时序预测 + 策略头"前身；Controller 只依赖 z/h 就够，印证了"世界模型表征可以简化策略"
2. **对 VLA + 世界模型组合的启示**：
   - 世界模型可以提供**未来特征**给 VLA 做规划（类似 h_t 的作用）
   - 梦境/仿真数据可扩充 VLA 训练数据（数据增强方向）
   - 温度 τ 调节不确定性 → 防止策略利用模型漏洞，是模型辅助 RL 的重要超参
3. **学习价值**：这篇是"世界模型"公认开山之作，理解它 = 理解后续 Dreamer、Sora、Genie 的源头（从"潜空间预测"到"像素级生成"的演进）

## 8. 关键概念速查

| 概念 | 定义 |
|------|------|
| 世界模型 | 学习环境转移函数 `P(s_{t+1} | s_t, a_t)` 的生成模型 |
| VAE | 变分自编码器，压缩高维观测到潜空间 |
| MDN-RNN | 混合密度网络 + RNN，输出多模态概率分布的循环预测模型 |
| CMA-ES | 协方差矩阵自适应进化策略，适合低维黑盒优化 |
| 温度 τ | 采样随机性控制旋钮，平衡环境"真实感"与"可利用性" |
| 梦境训练 | 在潜空间模拟环境中训练策略，再迁移到真实环境 |

## 9. 一句话评论

> 用"大世界模型 + 小控制器"的分工，把 RL 的难问题（信用分配）转换成监督学习的好问题——世界模型负责想象，控制器只需信任想象。这个设计哲学贯穿了此后所有的 model-based 具身智能研究。
