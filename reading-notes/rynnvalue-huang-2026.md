## 1. 一句话概括

用**时间距离（temporal distance）**——从当前观测到语言指定目标的有向 cost-to-go——取代"偏好对"和"归一化进度 [0,1]"作为奖励模型的监督目标，训练出通用机器人价值基础模型 **RynnValue**：标签直接从时间戳导出，因此在 7,000+ 小时、约 300 万条指令条件片段的异构数据上无需任何偏好标注即可规模化；再通过基于势能的 reward shaping 变成稠密奖励接口，真实世界线上 RL 成功率从 52.5% 提升到 72.5%。

## 2. 核心判断表

| 判断 | 结论 |
|------|------|
| 解决的问题 | 通用策略的 RL 微调瓶颈不在策略容量，而在**奖励监督**：手工奖励不泛化、稀疏奖励长程无效 |
| 核心批判对象 | 现有通用奖励模型依赖任务内锚点（偏好/演示/归一化进度），跨具身、跨数据源难迁移 |
| 替代方案 | **时间距离**：从观测到语言目标的有向 cost-to-go，标签直接来自时间戳 → preference-free、跨具身统一 |
| 关键工程问题 | 多帧模型会走捷径（利用采样间隔/序列位置/历史 value 外推）→ 三个反捷径设计 |
| 效果 | 无偏好训练 τa=0.675 反超偏好监督 SOTA（0.655），超 progress-only（0.292）两倍多；零样本泛化到未见任务/具身/视角 |
| 定位 | 奖励模型 → **价值基础模型**：单一可复用接口（temporal distance），而非任务特定启发式 |

## 3. 背景与动机

| 现状 | 问题 |
|------|------|
| 通用策略越来越多用 RL 训练 | 奖励监督成瓶颈：手工奖励不泛化、稀疏成功信号对长程行为引导弱 |
| 通用奖励模型用任务内锚点（偏好/参考演示/局部状态比较，如 Robometer [16]、RoboReward [15]） | 监督绑定特定轨迹/比较集，异构数据难以复用 |
| 常见退路：归一化 [0,1] 进度 | 是**轨迹内坐标**而非目标条件 cost-to-go，与控制论中"value"的标准定义不对齐，跨时长/具身/任务结构不一致 |

**主张**：把框架从"给轨迹级锚点评分的奖励模型"转为"预测目标条件 cost-to-go 的**价值基础模型**"——时间距离是天然规模化、可统一的监督目标与奖励接口。

## 4. 数据配方：时间距离重标注（Section 3.1）

| Soft-FOLD [35] | 1,542 | 1,542 | 1 | per-file coarse task |
| **合计** | **1,671,313** | **3,091,969** | 223,395 | — |

覆盖：单臂/双臂移动操作/桌面双臂/灵巧手/仿真具身/第一人称人类演示 + 多种相机配置。

**重标注流程**：
1. 子任务切分（有原生时间标注则用，否则整段作为粗片段）
2. **完成截止点（cutoff）重标注**：处理完成后多余动作，按比例/时长裁剪
3. 标签直接从时间戳生成：截止点前观测的标签 = 剩余时间；截止点及之后 = 0
4. Qwen3-VL-27B 生成片段级描述（只监督语言分支，不影响时间目标）

**关键**：无需偏好对、无需进度归一化——"时间戳 + 截止点"即可统一所有数据。

## 5. 模型架构（Section 2）

基于 **RynnBrain** [5]（开放具身基础模型）继续预训练，输入 = 指令 ℓ + 具身元数据 m + K=8 帧观测。

### 5.1 分组时间查询（Grouped Temporal Queries）
- 单 query token 是信息瓶颈（要同时总结物体构型、机器人-物体交互、中间任务阶段、完成证据）→ 每个时间预测用 **N=8 个重复 query token** 组
- 每帧观测插入绝对查询组 Vᵢ；从第二帧起在 Vᵢ 前插入相对查询组 Rᵢ₋₁
- 组内 token 双向注意力互见；组间通过 **value-isolation attention** 完全隔离
- 组内 N 个隐状态**拼接**（非平均）→ Nd 维表示，保留互补信息

### 5.2 双分布头（Continuous Temporal Readouts）
| 头 | 目标 | 范围 | 量化 |
|----|------|------|------|
| ValueHead（绝对） | 观测到完成截止点的剩余时间 | [0, 512]s | 256 个 symlog 均匀 bin |
| RelativeHead（相对） | 相邻（呈现序）观测的有符号时间位移 | [−256, 256]s | 256 个 symlog bin |

- **symlog binning**：压缩大数值尾部、近零目标不失真，跨宽动态范围稳定回归
- **two-hot 目标**：连续目标由最近两个 bin 精确表示，梯度幅度与目标尺度解耦
- 推理：softmax 期望 bin 中心 + symexp 反变换 → 连续时间估计
- LM head 保留但仅用于自然语言输出，不参与数值预测

### 5.3 价值隔离注意力（Value-Isolation Attention）★ 核心设计
- 不同观测的 value query 组**互相不可见**（同组仍互见）
- 上下文 token 也不能 attend 时间查询 token → 之前的值预测无法通过后续表示间接传播
- 每个时间估计必须**锚定在对应视觉观测 + 任务语义**上，杜绝"从历史 value 外推"的平滑捷径

## 6. 训练配方：反捷径三件套 + 多目标（Section 3.2）

| 设计 | 机制 | 对应捷径 |
|------|------|---------|
| **随机时间采样** | K=8 帧在非均匀时间戳采样，打破近似等差数列 | 固定采样间隔 → 价值曲线可被位置外推 |
| **时间顺序打乱** | 50% 样本不打乱；其余"前向偏置随机游走"（rewind 概率 0.3）；相对目标按呈现序可为正或负 | 序列位置 ↔ 任务进度强关联 |
| **价值隔离注意力** | 见 5.3 | 跨查询组值外推 |
| **指令不匹配增强** | 10% 样本替换为其他轨迹的指令，语言分支监督 Match:No / Success:No；绝对时间损失掩码，相对损失保留 | 语言-视觉不一致时仍可靠 |

**联合目标**（三个交叉熵）：
```
L = L_abs + L_rel + 2·L_lang
```
- L_abs：绝对时间距离（指令不匹配时掩码 ω=0）
- L_rel：相对时间位移（与指令无关，始终保留）
- L_lang：结构化语言输出 `{Video Description, Match, Success}` 的 token 级 CE——成功预测通过语言目标学习，不设独立分类头

## 7. 推理与奖励接口（Section 3.3）

- 推理时禁用采样增强，观测按时间顺序排列；value-isolation 保持激活
- **时间距离取反得势能**：Φ_t = −v_t（完成前为负，接近目标趋零）——保留时间尺度而非归一化到 [0,1]
- **Potential-based reward shaping** 转稠密奖励：
```
r'_t = κ(γΦ_{t+1} − Φ_t) + (0 if t=T 且成功, else −1)
```
- 保留稀疏完成项（奖励模型可能有噪声，成功标签干净可靠，人工标注）

## 8. 实验结论（Section 4）

### 8.1 基准：RBM-EVAL-OOD 轨迹排序（Kendall's τa ↑）
| 方法 | 监督类型 | 平均 τa |
|------|---------|---------|
| Robometer (RBM-1M) | 进度+轨迹偏好 | 0.655 |
| RoboReward-8B / 4B | 偏好 | 0.465 / 0.502 |
| Dopamine-GRM-2.0-8B | 偏好 | 0.453 |
| Robometer (Progress only) | 仅进度 | 0.292 |
| **RynnValue-4B** | **无偏好（时间距离）** | **0.670** |
| **RynnValue-8B** | **无偏好（时间距离）** | **0.675 ★** |

- 8B 在 USC Franka/Koch/Trossen 三项第一；4B 在 UTD SO101 第一
- 无偏好方法里 6 个数据集全最优；性能 4B 已很强、8B 增益小 → **收益来自时间距离配方与架构设计，而非单纯模型规模**

### 8.2 消融（τa 变化）★ 印证反捷径设计
| 变体 | 平均 τa | 启示 |
|------|---------|------|
| 全模型 (8B) | **0.675** | — |
| 去掉顺序打乱 | **0.189**（最大降幅） | 序列位置是进度强代理 |
| 均匀采样替代随机采样 | 0.379 | 固定间隔可被利用 |
| 去掉价值隔离注意力 | 0.482 | 值外推捷径 |
| 去掉语言监督 | 0.537 | 语义锚定有用 |
| 去掉相对损失 | 0.627 | 局部时间信号补全局锚定（USC Trossen 1.000→0.639） |

### 8.3 指令-轨迹对齐
混淆矩阵归一化对角线 margin：RynnValue **0.79** > 最强基线 0.67 → 奖励锚定语言目标而非通用视觉进度。

### 8.4 缩放分析 ★
- **episode 数量**（任务固定）：几乎立即饱和，更多同类数据无增益
- **任务多样性**（episode 数固定）：全区间单调下降误差
- 结论：**异构数据配方的价值是多样性而非体量**——与 Cosmos"数据决定上限"的策展哲学呼应

### 8.5 价值曲线案例
对比 Robometer：RynnValue 对试错/回归（value drop）反应更敏锐、恢复后上升更平稳、接近完成时对扰动仍敏感（避免奖励提前饱和）。

### 8.6 真实世界 RL（双臂 Franka + 腕部/第三方相机，4 任务，零样本奖励标注）
| 设置 | RynnValue | Robometer | Sparse |
|------|-----------|-----------|--------|
| Online RL | **72.5%** | 52.5% | 48.8% |
| Offline RL (IQL) | **82.5%** | 63.8% | 22.5%（SFT 23.8%） |

- 线上：Steak Serving +30pp、Bimanual Box Transfer +35pp（相对 Robometer）
- 线下：Bread Basket 100%@16.8 chunks；Box-in-Drawer 与 Bimanual 是 SFT 零成功任务，RynnValue RL 可解
- 局限场景：Box-in-Drawer 在线增益有限——仅看第三人称 RGB，视觉相近构型对应抓取稳定性/对齐差异大，中间奖励难校准（视觉模糊 + 精度敏感）

## 9. 局限与讨论

| 局限 | 说明 |
|------|------|
| 短窗口 | 从短采样窗口估时间距离；长时程/流式推理待扩展（作在线奖励源） |
| 最小时间假设 | 目标隐含 minimum-time 目标；加入能量/安全/精度代价可丰富价值语义 |
| 视觉歧义 | 仅 RGB 第三人称，精密任务（如抽屉对齐）中间奖励难校准 |
| 时间戳依赖 | 标签依赖可靠时间戳与截止点重标注；后完成动作需启发式裁剪 |

## 10. 与我的研究方向的联系

1. **这是"VLA + RL 微调"链路中的奖励瓶颈解法**：我 12 个月计划里 VLA 微调部分（Diffusion Policy、π0 路线）直接受益——π0.5/π*0.6 用 RL 从经验学习，奖励正是其瓶颈；RynnValue 提供了 preference-free、零样本可用的稠密奖励接口，可与"用世界模型评估策略"（Cosmos 笔记第 3 节用途①）互为补充：WFM 模拟世界，RynnValue 给信号。
2. **时间距离 ↔ 世界模型主线的深层连接**：temporal distance 是 goal-conditioned cost-to-go，本质是"预测未来"的另一种表达（多长时间到达目标）；与 World Models / 预测学习在信息层面同源——未来可探索"世界模型预测剩余时间"的统一建模。
3. **与脑启发架构的呼应**：时间距离价值 ≈ 强化学习中的"奖赏预测误差 / 多巴胺式价值编码"；RynnValue 对回归/失败的敏锐响应对应基底节价值系统的实时性——可放入我模块化架构中"小脑/基底节=价值与校正"的槽位。
4. **数据多样性 > 数据量**：缩放分析（§8.4）是方法论层面的重要证据——与我的数据策展思考（Cosmos 笔记）一致，异构具身数据是价值模型泛化的关键。
5. **反捷径三件套是可迁移的通用技术**：随机时间采样 + 顺序打乱 + 信息隔离注意力，对任何"多帧时序判别/回归"任务（价值、奖励、进度、成功检测）都有防过拟合价值。

## 11. 关键概念速查

| 概念 | 定义 |
|------|------|
| Temporal distance | 从观测到语言目标的有向 cost-to-go（剩余时间），标签直接来自时间戳 |
| Value Foundation Model | 预测目标条件价值的通用模型（RynnValue），作为单一奖励/价值接口 |
| RBM-EVAL-OOD | Robometer 提出的 OOD 轨迹排序评测集（976 条、6 个跨机构数据集） |
| Kendall's τa | 轨迹质量排序与预测排序的一致性系数 |
| Progress [0,1] | 轨迹内归一化进度（被批判的锚点） |
| symlog + two-hot | 宽动态范围回归的离散化方案：symlog 压缩 + 相邻 bin 双热点编码 |
| Value-isolation attention | 不同观测的 value 查询组互不可见的注意力掩码，防值外推捷径 |
| Temporal-order shuffling | 训练时打乱观测时序，切断序列位置↔进度关联 |
| Potential-based shaping | 用势能差 γΦ_{t+1}−Φ_t 构造稠密奖励（不改变最优策略） |
| IQL | Implicit Q-Learning，离线 RL 算法（Kostrikov et al. 2022） |
| DSRL | Diffusion Steering via RL，在线策略学习框架（本文用于在线 RL） |

## 12. 一句话评论

> 奖励模型之所以难规模化，是因为我们把监督锚在"某个任务内部"（偏好、进度）；RynnValue 把锚换成"到目标的剩余时间"这一跨具身、跨数据源天然一致的量，顺手用三个反捷径设计把多帧价值学习做稳——结果是零偏好标注反超偏好监督 SOTA。对做 VLA+RL 的人来说，它给出了"奖励从哪来"的务实答案：不用标偏好，用时间戳。剩下的功课是让价值语义更丰富（能量/安全代价）、窗口更长、能读懂更微妙的视觉证据。
